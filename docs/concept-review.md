## Review questions

Ask these in order before discussing personal visual preference:

1. Who does this page appear to be for?
2. What does the visitor believe they will leave with?
3. What role does First Draft play: facilitator, tool, compiler, curriculum, or host?
4. What feels credible? What sounds ahead of the evidence?
5. What would the visitor expect after pressing the CTA?
6. Which concept best matches what should be true after the AppDev trial?

- Define analytics events only when a real conversion action exists.
- Prototype the selected scroll sequence in code before committing to its production motion budget; include a reduced-motion presentation from the start.
