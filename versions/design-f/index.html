THE WORKING SESSION

FOUR DECISIONS
ONE REVIEWED PLAN

  1. ACCESS / TYPES OF USERS

    Who uses the Reading List—visitors, signed-in readers, or an admin? Does each reader need an account?

    You Readers sign in to keep their own lists. Visitors see shared notes; an admin curates the catalog.

  2. BOOK / FIELDS AND STATUS

    What belongs on a book—title, author, publication date, description, note, and reading status? Which are required?

    You Keep all six. Require title and author; status moves from interested to reading to finished.

  3. ACTIONS / COMPLETE FIRST LOOP

    What must work end to end: add a book, see My Books, view a book, mark it read, or share its notes?

    You All five. Readers can manage their list and share a book’s notes.

  4. PLATFORMS / PRIORITIES

    Which platforms matter most: web, iOS, Android, or all of the above?

    You All of the above. Review each client’s support gaps before compiling.
