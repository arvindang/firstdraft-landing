# Temporary scroll films

`cerca.mp4` and `illustrative.mp4` are short, scrub-friendly encodes of Arvin's existing portfolio walkthroughs. Their matching JPEGs are posters from the same source. They are interaction references only and do not depict a First Draft application.

Replace the two videos and posters in this folder when First Draft web and native recordings are available. The video elements in `../index.html` can keep their current paths, and `../middle.js` will continue to drive both with the scroll-video-scrubber plugin.
